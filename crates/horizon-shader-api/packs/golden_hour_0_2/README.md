# Golden Hour (shader API 0.2)

[Golden Hour](../golden_hour) written for shader API 0.2 ([shaders-reference-0.2.md](../../../../docs/api/shaders-reference-0.2.md)):
the same sky and post passes in linear light, and a `[tonemap]` stage of its own. 0.2 is experimental, so this is a
test pack of the SDK: the game refuses it and the registry doesn't list it. Check it with
`horizon-shader check crates/horizon-shader-api/packs/golden_hour_0_2`.
